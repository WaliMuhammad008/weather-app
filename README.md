# Weather App

A responsive weather application that allows users to search for any city and view current weather information using a weather API.

## Features

- Search weather by city name
- Display current temperature
- Show weather conditions
- Display humidity and wind speed
- Responsive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## Description

This project fetches real-time weather data from an API and displays useful weather information in a simple and user-friendly interface. The application provides accurate weather details based on the searched city.
